# ATLAS Simple File Editor

[![Open the ATLAS Plugin Repository install test page.](https://img.shields.io/badge/ATLAS-Install%20Test-0f8f83?style=for-the-badge)](https://rockbaer2007.github.io/atlas-plugin-repository-demo/install.html)

[![ATLAS Repository hinzufuegen](../../assets/atlas-repository-button.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Frockbaer2007%2Fatlas-plugin-repository-demo)

Demo plugin for the ATLAS plugin repository workflow.

This plugin is intentionally metadata-only for the first repository tests. It is
used to verify:

- repository loading
- icon, logo and preview rendering
- package installation
- version update detection
- package removal

The planned real plugin direction is a compact Home Assistant file editor with
ATLAS styling.
