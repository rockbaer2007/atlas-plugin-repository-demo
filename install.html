ATLAS Plugin Repository Demo

Plugin-Repository testen

Diese Seite ist die ATLAS-Zwischenseite für das Demo-Repository. Der Button kopiert die ATLAS-Repository-URL für die Administration.

ATLAS Administration

Füge die kopierte URL in ATLAS Administration ein, um Vorschau, Installation, Update und Entfernen zu testen.

  1. ATLAS Administration öffnen.
  2. ATLAS Repository hinzufügen auswählen.
  3. URL einfügen, Repository prüfen und danach Hinzufügen.

Einordnung

Das ist ein ATLAS Plugin-Test-Repository. Home Assistant Add-on-Repos gehören in Home Assistant, ATLAS Plugin-Repos gehören in ATLAS Administration.
